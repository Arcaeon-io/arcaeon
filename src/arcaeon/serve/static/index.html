This dashboard is served by arcaeon serve on this computer only (127.0.0.1). It reads the same records and runs the same checks as the arcaeon command, and it can only open files inside the folder the server was started for.

Every answer is one of a few fixed words. A green answer means the check ran to the end and held. COULD NOT LOOK is never green: it means part of the record could not be read, so nobody should sign off on it yet.

Nothing here leaves this machine, and nothing here needs an account.
