- **L4-03 (branch b200-t6d-gateways).** Added the Docker MCP Gateway after-interceptor `arcaeon gate mcp-after`, also runnable as `python -m arcaeon.connect.docker_after`, for `--interceptor 'after:exec:arcaeon gate mcp-after --config FILE'`. It reads the tool-call response JSON on stdin (a CallToolResult, a JSON-RPC response, or request+response) and prints it back after the L4-02 check: passed with the verdict, or replaced by an isError REFUSED result. It verifies the envelope a server put under `_meta["dev.arcaeon/bundle"]` (on a content block, or on the result when it has one block) against the bytes it seals, through gate.decide, and applies the enforce mode. VERIFIED passes with `_meta["dev.arcaeon/verdict"]`. A refusal (BROKEN; COULD NOT LOOK, including no bundle, on act/pay/irreversible) replaces the result with `isError: true` and a REFUSED text, and the tool's output is withheld.
