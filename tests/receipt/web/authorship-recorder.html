Authorship Receipt recorder

Records the edit stream for one writing session, entirely in this browser tab.

What this page does and does not do. This page never sends anything anywhere. Nothing here touches the network; there is no server, no analytics, no sync. Everything stays in this tab until you export it yourself. Exporting produces a file that records when text was typed, pasted, deleted, or left idle, and folds each event into a running hash as it happens. It does not prove a human typed the words: software can emit the same events. It is process evidence, not a humanity test, and it says nothing about whether pasted text was written by the author or by a model.
