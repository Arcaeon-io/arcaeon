## connect chatgpt
arcaeon connect chatgpt  (ChatGPT, remote-connector, macos)
confirmed: yes
source: https://developers.openai.com/plugins/deploy/connect-chatgpt (read 2026-09-27)
note: the page also names a Secure MCP Tunnel, which arcaeon does not set up
ChatGPT reaches outside tools through remote connectors or GPT Actions, and both need a public HTTPS address.
arcaeon serve binds 127.0.0.1 only (loopback), so it is not one.
GPT Action manifest: docs/schemas/gpt_action_openapi.json in the source tree, or `arcaeon schema --format gpt-action --out gpt_action.json`; its server url is a placeholder to replace.
needs a public URL, which is a deploy decision
