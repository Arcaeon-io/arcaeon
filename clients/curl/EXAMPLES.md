# arcaeon serve with plain curl

GENERATED by `tools/gen_curl_examples.py` from `docs/openapi.json`; do not edit by
hand (`py tools/gen_curl_examples.py --check` fails on drift). Every example below
is run, in this order, against a loopback server by
`tests/heavy/test_kh1_three_languages.py`, which checks the answer each one names.

20 examples, one per free route. Not exampled, because it spends: `POST /v1/seal`.

## Before you start

Start a server in an empty directory and keep it running; paths in the bodies are
relative to that directory (the server refuses any path outside it). The lines are
POSIX shell: bash, zsh, Git Bash, WSL, macOS. In PowerShell call `curl.exe` and put
each body in a file sent with `--data-binary @body.json`.

```sh
arcaeon serve --port 0          # prints: listening on http://127.0.0.1:NNNN
# in a second shell, in the same directory:
ARCAEON=http://127.0.0.1:NNNN   # the address it printed (http://127.0.0.1:8787 by default)
TOKEN=$(arcaeon serve --print-token)
```

Every `/v1` route answers HTTP 200 whenever a verdict was reached, good or bad, with
the verdict and an integer `exit` in the body: 0 good, 1 a bad finding, 2 bad usage,
3 COULD NOT LOOK. A verdict never rides in the HTTP status. 400 is bad usage, 401 a
missing or wrong token, 413 a body over 10 MB.

## Setup

Three inputs the examples read and no example makes.

Write `mandate.json`: a mandate for the mandate check (no route writes one).

```sh
cat > mandate.json <<'EOF'
{
 "who": "demo-agent",
 "allowed_acts": [
  "search_*",
  "place_order"
 ],
 "forbidden_acts": [
  "delete_*"
 ],
 "spend_cap": {
  "amount": "60.00",
  "currency": "USD"
 }
}
EOF
```

`POST /v1/log`: the agent side's tape: one call.

```sh
curl -s -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" -d '{"ledger": "tape_agent.jsonl", "row": {"evt": "tape_call", "tape": "arcaeon-tape/1", "side": "agent", "idx": 1, "tool": "search", "req": "sha256:req-1", "resp": "sha256:resp-1"}}' "$ARCAEON/v1/log"
```

`POST /v1/log`: the tool side's tape: the same call.

```sh
curl -s -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" -d '{"ledger": "tape_tool.jsonl", "row": {"evt": "tape_call", "tape": "arcaeon-tape/1", "side": "tool", "idx": 1, "tool": "search", "req": "sha256:req-1", "resp": "sha256:resp-1"}}' "$ARCAEON/v1/log"
```

`POST /v1/readings`: the first reader's reading of one claim.

```sh
curl -s -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" -d '{"ledger": "readings_a.jsonl", "reader_id": "reader-a", "provider": "local", "claim_id": "c1", "claim": "Refunds are accepted within 30 days of purchase.", "criterion": "Is the claim stated in the refund policy text?", "reading": "yes"}' "$ARCAEON/v1/readings"
```

## Examples

### GET /health

Is the server up.

```sh
curl -s "$ARCAEON/health"
```

Answers: a small JSON object saying the server is up, HTTP 200.

### GET /openapi.json

This API as an OpenAPI 3.1 document.

```sh
curl -s "$ARCAEON/openapi.json"
```

Answers: this API as an OpenAPI 3.1 document, HTTP 200.

### GET /

The local dashboard (HTML).

```sh
curl -s -H "Authorization: Bearer $TOKEN" "$ARCAEON/"
```

Answers: the local dashboard page (HTML), HTTP 200.

### POST /v1/log

Append one JSON row to a ledger; returns the new chain value.

```sh
curl -s -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" -d '{"ledger": "calls.jsonl", "fields": {"tool": "search", "query": "refund policy"}}' "$ARCAEON/v1/log"
```

Answers: `"exit": 0`, HTTP 200.

### POST /v1/verify

Check a ledger's chain: VERIFIED / BROKEN / COULD NOT LOOK.

```sh
curl -s -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" -d '{"ledger": "calls.jsonl"}' "$ARCAEON/v1/verify"
```

Answers: `"verdict": "VERIFIED"`, `"exit": 0`, HTTP 200.

### POST /v1/reconcile

Two tapes and a counter: MATCHED / MISSING / ALTERED / COULD NOT LOOK.

```sh
curl -s -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" -d '{"tape_a": "tape_agent.jsonl", "tape_b": "tape_tool.jsonl"}' "$ARCAEON/v1/reconcile"
```

Answers: `"verdict": "MATCHED"`, `"exit": 0`, HTTP 200.

### POST /v1/pin

Record a ledger head in a local witness file under the served root (remote pin is the paid lane).

```sh
curl -s -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" -d '{"ledger": "calls.jsonl", "witness": "pins.jsonl", "ns": "demo"}' "$ARCAEON/v1/pin"
```

Answers: `"exit": 0`, HTTP 200.

### POST /v1/readings

Submit one reader's reading of a claim, chained into a readings ledger.

```sh
curl -s -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" -d '{"ledger": "readings_b.jsonl", "reader_id": "reader-b", "provider": "local", "claim_id": "c1", "claim": "Refunds are accepted within 30 days of purchase.", "criterion": "Is the claim stated in the refund policy text?", "reading": "yes"}' "$ARCAEON/v1/readings"
```

Answers: `"exit": 0`, HTTP 200.

### POST /v1/second-read/compare

Line up two readings ledgers: COMPARED / MISSING / BROKEN / COULD NOT LOOK.

```sh
curl -s -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" -d '{"a": "readings_a.jsonl", "b": "readings_b.jsonl"}' "$ARCAEON/v1/second-read/compare"
```

Answers: `"verdict": "COMPARED"`, `"exit": 0`, HTTP 200.

Then issue that comparison as a local receipt (the CLI's --receipt; no route issues one):

```sh
arcaeon second-read compare readings_a.jsonl readings_b.jsonl --receipt receipt.json
```

```sh
curl -s -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" -d '{"receipt": "receipt.json"}' "$ARCAEON/v1/receipt/verify"
```

Answers: `"verdict": "VERIFIED"`, `"exit": 0`, HTTP 200.

### POST /v1/handshake/propose

Propose terms to another agent; each side keeps its own ledger.

```sh
curl -s -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" -d '{"ledger": "agent_a.jsonl", "terms": {"task": "summarize the refund policy", "fee": "5.00", "currency": "USD"}}' -o proposal_answer.json "$ARCAEON/v1/handshake/propose"
```

Answers: `"exit": 0`, HTTP 200.

Then hand the proposal to the other side: wrap it in the accept body:

```sh
python -c "import json; a = json.load(open('proposal_answer.json')); json.dump({'ledger': 'agent_b.jsonl', 'proposal': a['proposal']}, open('accept.json', 'w'))"
```

### POST /v1/handshake/accept

Countersign proposed terms.

```sh
curl -s -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" -d @accept.json "$ARCAEON/v1/handshake/accept"
```

Answers: `"exit": 0`, HTTP 200.

### POST /v1/handshake/verify

Line up both sides' ledgers: AGREED TERMS / DIFFERENT TERMS / MISSING / COULD NOT LOOK.

```sh
curl -s -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" -d '{"a": "agent_a.jsonl", "b": "agent_b.jsonl"}' "$ARCAEON/v1/handshake/verify"
```

Answers: `"verdict": "AGREED TERMS"`, `"exit": 0`, HTTP 200.
